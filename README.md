# AES-256-GCM Secure Encryption Tool v3.1

一个基于现代密码学标准的纯客户端安全加密/解密工具。采用**单文件架构**与**零信任（Zero-Trust）设计**，确保所有敏感数据均在浏览器本地安全处理，绝不经过任何云端服务器。

🔗 **Live Demo:** [aes-eight.vercel.app](https://aes-eight.vercel.app/)

---

## ✨ 核心特性 (Key Features)

### 🔐 文本加密
- **AES-256-GCM 认证加密**：调用浏览器原生的 `Web Crypto API` 进行 GCM 模式加密
- **PBKDF2 密钥拉伸**：60,000 次哈希迭代加盐，有效抵御暴力破解
- **实时密码强度检测**：输入密码时实时显示强度等级和要求满足状态

### 📁 文件加密
- **ZIP 文件加密**：支持对 `.zip` 文件进行 AES-256-GCM 加密
- **安全文件格式**：加密文件包含签名、版本号、文件哈希验证
- **防篡改保护**：解密后自动验证文件完整性

### ⚙️ 个性化设置
- **背景图片**：支持本地上传或 URL 链接设置自定义背景
- **主题切换**：浅色/深色/跟随系统三种模式
- **多语言支持**：中文/英文界面切换
- **自定义光标**：酷炫的跟随鼠标动画效果

### 🔒 安全特性
- **零知识隐私保护**：所有操作在客户端本地完成，零网络请求
- **尝试次数限制**：5 次失败后锁定 5 分钟
- **渐进式延迟**：失败后逐步增加等待时间
- **CSP 安全策略**：防止 XSS 攻击

## 📖 功能说明 (Features)

### 文本加密/解密
1. 在"输入文本"框中输入要加密的文本
2. 设置符合要求的密码（至少12位，包含大小写字母、数字、符号）
3. 点击"加密"按钮，加密结果将显示在"输出结果"框中
4. 解密时，将加密文本粘贴到"输入文本"框，输入密码后点击"解密"

### 文件加密/解密
1. 切换到"文件加密"标签页
2. 拖拽或选择 `.zip` 文件
3. 输入密码（要求与文本加密相同）
4. 点击"加密文件"下载 `.enc` 加密文件
5. 解密时，选择 `.enc` 文件，输入密码后点击"解密文件"

### 个性化设置
- **背景图片**：设置页面 → 背景图片 → 选择本地图片或输入图片 URL
- **主题切换**：导航栏右上角太阳/月亮图标，或设置页面中选择
- **语言切换**：导航栏右上角下拉框，或设置页面中选择

## 🔐 安全机制 (Security)

### 密码要求
- 最少 12 位字符
- 包含大写字母 (A-Z)
- 包含小写字母 (a-z)
- 包含数字 (0-9)
- 包含特殊字符 (!@#$%^&*)

### 防暴力破解
- 最多允许 5 次连续失败尝试
- 失败后逐步增加延迟（0s → 5s → 10s → 30s → 5min）
- 达到上限后锁定 5 分钟
- 安全状态 24 小时后自动过期

### 加密文件格式
```
签名(8字节) | 版本(1字节) | Salt(16字节) | IV(12字节) | 文件哈希(32字节) | 文件名长度(2字节) | 文件名 | 密文
```
